# 銚子旅行HTML 実装プラン

## プロジェクト構成
```
choshi-trip/
├── index.html        ← メインファイル（CSS・JS込み単一ファイル）
└── docs/
    └── plan.md       ← このファイル（実装記録・設計メモ）
```

## ファイル概要
`index.html` は単一HTMLファイル（CSS・JS込み）の銚子一日旅ガイド。
外部ライブラリ不使用、ビルド不要。ブラウザで直接開くか、HTTPサーバ経由で閲覧可能。

---

## 実装済み機能

### Phase 1 — レスポンシブCSS
- 768px・480px の2段階メディアクエリ
- モバイルでプランカードが縦積みに切り替わる

### Phase 2 — 時刻表リンク
- トレインバーに Yahoo!乗換・銚子電鉄時刻表リンク
- フッターにも同リンクを配置

### Phase 3 — Google Mapsリンク
- タイムライン各スポットに 📍 リンク
- 犬吠埼灯台・地球の丸く見える丘・君ヶ浜・外川漁港・銚子駅

### Phase 4 — 写真ライトボックス
- プラン写真・ハイライト画像クリックで拡大表示
- サムネイル3枚はグループ化して ◀▶ ナビ
- 閉じる: ✕ボタン・背景クリック・ESCキー

### Phase 5 — 詳細モーダル
- 各プランカードに「詳細・費用・アドバイスを見る →」ボタン
- タイムライン・費用テーブル・交通リンク・アドバイスを動的生成
- 閉じる: ✕ボタン・backdrop クリック・ESCキー

### Phase 6 — スティッキーナビゲーション
- ヒーローを越えたら固定ナビバーが登場
- Plan 01〜03・食事・見どころへのアンカーリンク

### Phase 7 — 白ベース・ガイドブック風リデザイン
- ヒーロー: 暗い写真背景のまま（ドラマチック演出を維持）
- トレインバー以降: 白/クリームベースの明るいデザイン
- プランカード: 白背景＋subtle box-shadow
- 食事セクション: 写真付きカード＋実店舗リンク
- 見どころ: 温かいベージュ背景
- フッター: 淡いベージュ、ダークテキスト

## カラーパレット

| 変数           | 値                       | 用途                         |
|---------------|--------------------------|------------------------------|
| `--bg`        | `#ffffff`                | ページ基本背景                |
| `--bg-warm`   | `#faf8f5`                | プランカード本文背景           |
| `--bg-section`| `#f2efe9`                | トレインバー・ハイライト・フッター |
| `--ink`       | `#1d2d3e`                | メインテキスト                |
| `--ink-sub`   | `rgba(29,45,62,.60)`     | サブテキスト                  |
| `--teal`      | `#2a8b8c`                | アクセント・リンク             |
| `--foam`      | `#3aa0a1`                | タイムライン時刻・イタリック体  |
| `--sand`      | `#9e6c2a`                | 価格・費用表示                 |

## プレビュー方法

```bash
# /tmp にコピーしてローカルサーバ起動（Claude Code の launch.json）
cp ~/Downloads/choshi-trip/index.html /tmp/choshi-travel.html
# → http://localhost:8765/choshi-travel.html
```

`~/Downloads/.claude/launch.json` の python3 HTTPサーバ設定（port 8765, --directory /tmp）を使用。
